# Brand assets

- `nivea-logo.png` — NIVEA logo (256 px, round, transparent corners), made from the logo file supplied for this project. Used in the header and on the login page (`BRAND_LOGO` in `assets/js/common.js`).
- `favicon.png` — 64 px version for the browser tab.

To replace the logo, overwrite `nivea-logo.png` (and `favicon.png`) and run `python3 tools/bump-version.py`.
